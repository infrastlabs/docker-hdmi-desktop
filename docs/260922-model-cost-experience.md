# 260922 | 模型积分成本与体验对比

> 背景：2026-09-22 整理 mHub 平台（商汤 API 平台）各模型在实际使用中的积分倍数、响应稳定性与心智表现，作为日常选型与省积分参考。数据来源于本日对话体验，非官方报价，可能随平台调整变化。
> 平台配额限制：每周 6w 积分、每月 60w 积分；DS V4 Flash 轻会话单轮积分消耗基数约 85。

## 一、积分倍数与体验

### 2、商汤平台计费演进：按次制 → 积分制

**时间线**：

- **2026-05-08**：商汤发布 SenseNova Token Plan，限时免费，按次制起点（首月每5小时1,500次）。
- **2026-08-28**：积分规则调整，由「按模型限次」切换为「双积分池」积分制（基于官方文档）。

| 维度 | 按次制（2026-05-08 ~ 08-27） | 积分制（2026-08-28 起） |
|---|---|---|
| 计量单位 | 调用次数 | token → 积分（1元=5000积分） |
| 商汤自家模型 | 1,500 次 / 5h | 通用积分池 |
| 第三方模型（DeepSeek/GLM 等） | 500 次 / 5h | 通用积分池 |
| 5 小时窗口 | 见上（按模型分档） | 60,000 积分 / 池 |
| 每周窗口 | 未明确 | 600,000 积分 / 池 |
| 积分池结构 | 单一（按模型独立限次） | 双池：通用池 + Flash-Lite 专属池 |
| 付费档 | 未上线（即将推出） | 日日新：即将上线；SenseAudio：Pro ¥199/Max ¥699/Ultra ¥1,899 |

- **按次制核心**：按模型独立限次、互不占用——商汤自家模型 1,500次/5h，第三方模型（DeepSeek/GLM 等）500次/5h。
- **积分制核心**：双积分池（通用 + Flash-Lite 专属，各池 5h 6万 / 周 60万）；用 Flash-Lite 优先扣专属池→不够再扣通用池，其他模型只扣通用池。
- **返赠活动（2026-08-28 起）**：每消耗 1 积分 Flash-Lite 专属积分，返赠 1 通用积分（按自然日汇总、每小时结算、30天有效，不占滚动窗口额度）。
- 来源：商汤官方文档 + 技术栈 jishuzhan.net/article/2093878702376144897（2026-08-30，基于官方文档解读）+ sensenova.cn/senseaudio.cn Token Plan 页。
- **平台区分**：双积分池规则源自日日新（sensenova.cn）TokenPlan 8-28 调整；但付费档 Pro/Max/Ultra（¥199/699/1,899）实际在 **SenseAudio 开放平台**（senseaudio.cn，开发者编程生态）上线，日日新本身仍为 Free 公测档（0元/月、6万积分/5h），付费档"即将上线"。

### 3、限流与稳定性备注

- 8月底起，仅 DS V4 两款（pro/flash）用户任务拥挤、常限流失败；K3 不挤队列、不限流。
- 同期（8月底）计费由按次限制改为**积分制**。
- sense6.8-flash-lite 在 9月上旬出现响应卡死，9月下旬已恢复流畅。
- 通用对策：**指令具体化、合并任务、减少模型往返试探**，可同时降低积分消耗与限流触发概率。

### 4、备注

- 模型均接入商汤 API 平台；平台积分配额：每周 6w、每月 60w，超限需等下一周期。
- 倍数为体验实测口径，非官方价目；缓存命中会显著拉低实际成本，故 Flash 实际开销可能远低于标称倍数。
- 后续若平台调整价格或新增档位，在本表追加并标注日期即可。

### 5、选型务实建议

#### 选型逻辑与数据印证

| 模型 | 实际痛点 | 文档数据印证 |
|---|---|---|
| GLM-5.2 | 缓存也 1/4 计费，积分刷得快 | 缓存命中 25%——四家里折扣最弱，其他三家是 2% / 3.3% / 10% |
| DS V4 Flash | 三方最省，但拥挤限流 | 缓存 2% 折扣最狠，但拥挤限流记录在案（见第3节） |
| sense6.8-flash-lite | 靠独立池返赠 | 8-28 返赠：消耗 1 专属积分返 1 通用积分（见第2节） |

**关键洞察**：sense6.8-flash-lite 的实际净成本可能接近 0——专属池积分消耗后 1:1 返还，通用池还能涨。这比 GLM-5.2 的"实打实扣"和 DS V4 Flash 的"便宜但拿不到"都划算。它的风险不在成本，而在三点：**不拥挤、服务稳、不降智**（9月上旬卡死是先例）。

#### 行动建议

- **当前主力 → sense6.8-flash-lite（2×）**：专属池 **1:1 返赠**使实际净成本趋近于零，优于 GLM-5.2（缓存仅 25% 折扣、积分掉得快）与 DS V4 Flash（便宜但拥挤限流、常拿不到）；风险点是服务稳定性与心智一致性——**祈祷不拥挤、服务稳、不降智**（9月上旬卡死是先例），另注意 256K 上下文截断。
- **日常 + 高重复上下文 → DS V4 Flash**：缓存命中率高时性价比拉满（2% 折扣最狠），bash/Dockerfile/文档/简单问答均能胜任；但拥挤限流是硬伤。
- **GLM-5.2（12×）**：偶尔用于中等复杂度任务，避免日常闲聊消耗；缓存命中仍按 **1/4（25%）** 计费，积分刷得快，性价比最差。
- **Kimi K3（25×）**：仅在啃不动的硬骨头（复杂架构、诡异 bug、长链推理）时临时切，不挤队列、不限流；尽量一次到位，减少往返。
