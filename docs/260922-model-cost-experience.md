# 260922 | 模型积分成本与体验对比

> 背景：2026-09-22 整理 mHub 平台（商汤 API 平台）各模型在实际使用中的积分倍数、响应稳定性与心智表现，作为日常选型与省积分参考。数据来源于本日对话体验，非官方报价，可能随平台调整变化。
> 平台配额限制：每周 6w 积分、每月 60w 积分；DS V4 Flash 轻会话单轮积分消耗基数约 85。

## 一、积分倍数与体验

### 1、积分倍数与行业定价对比（以 DS V4 Flash 为基准）

| 模型 | 倍数 | 行业定价（元/M token，高峰/空闲） | 备注 |
|------|------|------|------|
| DeepSeek V4 Flash | 1× | 输入 2 / 缓存命中 0.04（2%）/ 输出 8（高峰）；**空闲半价** | 基准档，最省；轻会话单轮**积分基数约 85**；**与 pro 共享 24h 内缓存**（重复上下文命中红利） |
| DeepSeek V4 Pro | 4× | 输入 9 / 缓存命中 0.30（3.3%）/ 输出 27（高峰）；**空闲半价** | 慢；与 flash 同挤队列，8月底起常限流失败；**缓存与 flash 共享**，性价比差 |
| GLM-5.2 | 12× | 输入 8 / 缓存命中 2（25%）/ 输出 28（无时段区分） | 常规编码/中等复杂度任务可用，但日常闲聊也按此消耗，不划算 |

> 行业定价说明（2026-09 核查，以官方最新页为准）：
> - **时段**：仅 DeepSeek 区分高峰/空闲——工作日 9:00-12:00、14:00-18:00 为高峰，其余（含周末、法定节假日全天）为空闲，**空闲价为高峰的一半**；GLM-5.2 / Kimi K3 无时段区分。
> - **缓存命中**：输入命中 KV 缓存的折扣价；DeepSeek flash/pro 共享 24h 缓存（高命中率时实际成本远低于标称）。
> - **Kimi K3**：中国区 ¥20 / ¥2（缓存）/ ¥100；全球 $3 / $0.30 / $15。
> - **sense6.8-flash-lite**：走商汤 Token Plan 积分订阅（1元=5000积分），公测期免费，不直接对应 token 单价。
> - 数据来源：DeepSeek api-docs.deepseek.com、智谱 bigmodel.cn、月之暗面 platform.kimi.com、商汤 sensenova.cn。

### 2、选型务实建议

- **日常 + 高重复上下文 → DS V4 Flash**：缓存命中率高时性价比拉满，bash/Dockerfile/文档/简单问答均能胜任。
- **sense6.8-flash-lite（2×）**：日常可用，心智够；注意 256K 上下文截断，分析大文件/大仓库时不如 Flash 缓存红利。
- **GLM-5.2（12×）**：偶尔用于中等复杂度任务，避免日常闲聊消耗。
- **Kimi K3（25×）**：仅在啃不动的硬骨头（复杂架构、诡异 bug、长链推理）时临时切，且尽量一次到位，减少往返触发限流。

### 3、限流与稳定性备注

- 8月底起，仅 DS V4 两款（pro/flash）用户任务拥挤、常限流失败；K3 不挤队列、不限流。
- 同期（8月底）计费由按次限制改为**积分制**。
- sense6.8-flash-lite 在 9月上旬出现响应卡死，9月下旬已恢复流畅。
- 通用对策：**指令具体化、合并任务、减少模型往返试探**，可同时降低积分消耗与限流触发概率。

### 4、商汤平台计费演进：按次制 → 积分制

8月底商汤 API 平台由"按次计费"切换为"积分制"，限制口径与计量单位均变化：

| 维度 | 按次制（8月底前） | 积分制（8月底后） |
|---|---|---|
| 计量单位 | 调用次数 | token → 积分（1元=5000积分） |
| Free 公测档 | 0元/月 | 0元/月 |
| 5 小时窗口 | 每模型 1,500 次 | 60,000 积分 |
| 每周/月度窗口 | FAQ 未明确 | 三层滑动窗口（5h/每周/月度） |
| 付费档 | 未上线（即将推出） | Pro ¥199 / Max ¥699 / Ultra ¥1,899 |
| 特殊模型 | 除外（清单未公布） | 见文档说明 |

- **按次制核心**：限"调用次数"而非 token 量，每模型每5小时1,500次（特殊模型除外）；Lite/Pro 付费档当时未上线。
- **积分制核心**：所有模型共享积分池，按 token 折算积分扣减；叠加5小时/每周/月度三层滑动窗口与并发上限，超额可开 Extra Usage 按量补扣。
- 来源：商汤 sensetime.com/cn/faq（8-27 快照）+ sensenova.cn/senseaudio.cn Token Plan 页；FAQ 未公布"特殊模型"清单与按次制是否有周/月维度，以控制台实际配额为准。

### 5、备注

- 模型均接入商汤 API 平台；平台积分配额：每周 6w、每月 60w，超限需等下一周期。
- 倍数为体验实测口径，非官方价目；缓存命中会显著拉低实际成本，故 Flash 实际开销可能远低于标称倍数。
